# Llama.cpp

[[llama.cpp]] is an open-source project for running LLaMA models efficiently on local hardware, including CPUs and mobile devices.

## Overview

llama.cpp is a C/C++ implementation of Meta's LLaMA model architecture, optimized for efficient inference on a wide range of hardware. It enables running large language models locally without requiring specialized GPU hardware.

## Key Features

- **CPU Inference**: Runs models on standard CPUs
- **Quantization**: Supports various quantization levels for efficiency
- **Cross-Platform**: Works on Windows, macOS, Linux, and mobile
- **High Performance**: Optimized for speed and memory efficiency
- **GGUF Format**: Custom model format for efficient loading
