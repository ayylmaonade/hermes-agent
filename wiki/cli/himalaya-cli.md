# Himlaya CLI

[[himalaya-cli]] is a command-line tool for interacting with AI models and services from the terminal.

## Overview

A CLI interface that allows users to leverage AI capabilities directly from their terminal, making it easy to integrate AI assistance into workflows and scripts.

## Key Features

- **Terminal Integration**: Works directly in the command line
- **Script-Friendly**: Can be used in automation and scripts
- **Multiple Models**: Support for various AI models and services
- **Easy Setup**: Simple installation and configuration
